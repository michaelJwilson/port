`run_cnaster_port --dispersion-rescale` fits per-spot NB and BB dispersions and scores each clone's pseudobulk at its moment-matched value, so clone size no longer sets the fitted dispersion.
`run_cnaster_port --per-state-dispersion` fits one NB and one BB dispersion per state, bounded by `--alpha-min` and `--tau-max` and optionally shrunk toward the pooled value by `--dispersion-prior-rows`.
