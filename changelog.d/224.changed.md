`run_cnaster_port` now installs the figure replacements by default, taking a run's plotting from 20.34 s to 3.84 s and its renderer buffers from 8,287 MB to 1,036 MB (#195). Figures are written at `dpi=150` with one rasterizing group per axes, so a default run no longer reproduces `cnaster`'s output byte for byte — pass `--no-figures` for an arm that does.
