`run_cnaster_port` now evaluates `cnaster`'s negative-binomial log-pmf with `scipy.special.gammaln` over the array instead of `lgamma` per element, hoisting the per-state term and caching `log(k!)` (1.78x across ten states). It agrees with `cnaster` to 8.6e-13 rather than to the byte, so a default run's emission values differ in the last few digits — pass `--no-approx` for an arm that reproduces bitwise.
