`run_cnaster_port` gained `--approx`, which evaluates `cnaster`'s negative-binomial log-pmf with `scipy.special.gammaln` over the array instead of `lgamma` per element (1.78x on the kernel). It is **off by default**: on a whole run it recovers nothing, and its 8.6e-13 disagreement with `cnaster` moves one segment's integer copy number by 3. A default run's output is unchanged.
