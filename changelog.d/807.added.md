Added `[layout.size] edge` to `port.sim.draw` manifests, required wherever `[layout.size]` is stated: `"grow"` keeps the polygon growing to its target at the array's edge, as before, and `"clip"` sizes it on the array continued past the edge (`draw.unbounded`), so a clone that runs off keeps only the spots that land on it.
Added `[cna] n_clones` as a law (`{law = "poisson", mean, minimum}`, drawn per truth by `port.sim.draw.resolved`), `[[slice]] clones = "all"`, and the required `[layout] unplaced = "refuse" | "stop"`, under which a clone no placement clears ends the layout and the truth is drawn on the clones placed.
Added the required `[layout] shape = "polygons" | "rectangles"` to `port.sim.draw` manifests: `rectangles` cuts the slices' shared frame into CalicoST's `p x p` grid by the clone count, normal's block at least `[layout] normal_share` of it.
Added `{law = "uniform", minimum, maximum}` to `[cna] n_clones` and `[layout] unplaced = "drop"`, under which a clone no placement clears is left out, the next placed, and the clones placed renumbered before the tree is drawn.
Added `[layout] radius` as a law, `{law = "normal", mean, sd, minimum}`: each drawn clone's radius, drawn in clone order before any placement.
