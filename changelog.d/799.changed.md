`cnaster.count_encoder.CountEncoder` is replaced by `port.patch.count_encoder.CountEncoder`, a `SWAPS` row with `cnaster`'s signature and codes: decoding gathers by each entry's code index (bitwise `cnaster`'s, 3.1x faster at dev_tree) and encoding sums by it, holding an `int32` index in place of the one-hot CSR maps (a quarter the bytes) (T- #799).
